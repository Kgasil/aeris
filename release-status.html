Instalação simples / Simple installation

O instalador experimental Windows x64 inclui o aplicativo e o runtime Python. Não é preciso instalar Python, usar terminal ou compilar. No GitHub Actions, baixe o artefato de teste e extraia apenas o Setup.exe; abra-o e confirme a instalação. O download direto permanente ficará disponível após revisão de redistribuição e publicação da prévia.

The experimental Windows x64 installer bundles the application and Python runtime. Download the test artifact, extract Setup.exe, open it and confirm installation. No Python or terminal required. A permanent direct download requires redistribution review and preview publication.
