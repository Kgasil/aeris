Foi preparada uma correção para a comparação de metadados de arquivos e a resolução do temporizador. Revalidação Windows pendente. First native test run: 8 failures, 24 errors, 4 skips. The second attempt stopped at patch SHA-256 verification before tests. The full corrected Fix 1 ZIP is published and the new build uses it directly. Native validation remains pending.

Windows CI · Regression test compatibility

Terceira execução: 399 testes, 394 aprovados, quatro ignorados e um erro na tentativa de substituir um arquivo aberto (WinError 5). A correção atual altera somente o teste de regressão: aceita o bloqueio pelo Windows desde que o arquivo continue íntegro, e verifica uma substituição concluída separadamente. Revalidação pendente.

Third run: 394 passed, four skipped, one error. Test-only adjustment for Windows open-file replacement semantics. Application code unchanged.
