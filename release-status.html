A primeira tentativa passou na verificação do ZIP e na preparação do Python, mas falhou nos testes nativos: 8 falhas, 24 erros e 4 testes ignorados. Foi preparada uma correção para a comparação de metadados de arquivos e a resolução do temporizador. Revalidação Windows pendente. A segunda tentativa foi interrompida na verificação SHA-256 do patch, antes dos testes. O ZIP corrigido completo (Fix 1) está publicado e a nova compilação o usa diretamente.

First native test run: 8 failures, 24 errors, 4 skips. The second attempt stopped at patch SHA-256 verification before tests. The full corrected Fix 1 ZIP is published and the new build uses it directly. Native validation remains pending.

Windows CI · Regression test compatibility

A correção atual altera somente o teste de regressão: aceita o bloqueio pelo Windows desde que o arquivo continue íntegro, e verifica uma substituição concluída separadamente. Revalidação pendente.

Third run: 394 passed, four skipped, one error. Test-only adjustment for Windows open-file replacement semantics. Application code unchanged.
