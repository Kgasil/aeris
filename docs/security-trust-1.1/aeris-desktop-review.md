## Código e dependências
- Triagem AST/sintaxe de 264 arquivos Python (incluindo testes); inventário de imports e chamadas sensíveis dos 123 módulos de desktop/aeris e main.py. Revisão focal de permissions.py, safe_input.py, companion.py, local_worker.py, chamadas de voz/OCR/tradução, acesso nativo, instalador e build. Não foi uma revisão manual linha por linha de todos os módulos, nem análise de cada binário/decompilação.
- Permissões de aplicação negadas inicialmente, concessão e revogação em sessão; não constituem sandbox do SO. Parser JSON estrito, leitura de arquivos com limites, validação de metadados. Limites documentados: corridas de arquivos, processos locais com mesma identidade e entradas externas.
- Companion usa HTTP loopback 127.0.0.1:11434, histórico limitado, resposta limitada e sem execução direta pelo modelo; sugestões analisadas por regras locais. Servidor/modelo pode encaminhar ou registrar dados. Microfone/voz invocam Windows PowerShell/System.Speech por função explícita, OCR invoca Tesseract externo, tradução Argos opcional na fonte. Não modificar/remover essas funções legítimas para tentar evitar alertas. A presença de subprocessos não prova malware.
- Build em ambiente virtual Windows x64, PyInstaller onedir, versão registrada 6.22.3, Inno Setup 6.7.4. Runtime CPython 3.14.10, OpenSSL 3.5.9, Tcl 9.0.4 e duas DLLs Microsoft; inventário/avisos preservados. Build-dependencies.txt: altgraph 0.17.5, packaging 26.4, pefile 2024.8.26, pip 26.2.2, pyinstaller 6.22.3, pyinstaller-hooks-contrib 2026.10, pywin32-ctypes 0.2.3, setuptools 84.2.1. requirements-build.txt fixa PyInstaller, mas não fixa transitivas por hash; inventário não é SBOM completo nem revisão de CVEs/licenças. Não houve consulta atualizada de vulnerabilidades das dependências.
- Inno Setup terms1: instalação por usuário (PrivilegesRequired=lowest), consentimento, atalho opcional, abertura após aceite opcional, sem autorun/updater/restart forçado ou exclusão de dados prevista no script. Instalador real não decompilado; correspondência do conteúdo instalado é evidência anterior de CI, não nova instalação.
- Leitura PE local: tabela de certificados (0,0) em Setup terms1 e Aeris.exe, consistente com NotSigned histórico. Inventário Windows anterior: 22/27 binários com status Valid, cinco NotSigned (Aeris.exe e quatro DLLs). Hashes conferidos, mas cadeia de confiança/revogação Authenticode não revalidada em Windows. Sem assinatura de editor da K&G Vision.
