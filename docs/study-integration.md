# Integration Engine II — v0.11.0a6

Learn → Flashcards: select a saved topic, enter an answer yourself, review the deck/question/answer and confirm. The plan title becomes the deck and topic title the question; it is not automatically generated or answered by AI.
Research → Learn: open a saved reference, choose an existing plan and estimated minutes, review and confirm. Only the reference title is copied. URL, authorship and private notes remain in Research. Duplicate normalized titles/questions are rejected. Transfers are one-way, single-record and session-scoped; use Protected Storage to save destination records.

Both flows require the integration permission and active source/destination tools. Revalidate the original immutable record, destination instance, arguments and capacity immediately before execution. Cancelling does not create a record. Existing destination editor drafts are not replaced.

Copilot now accepts the optional Aeris prefix, 'me lembre de', 'comece' and times like 14h or 14h30. Companion routes only user-entered/reviewed text to Copilot; no automatic execution of AI outputs. Actual model, microphone, voice and Windows DPAPI validation remain pending.

Web Lab is published independently on the website branch; website demonstrations are simplified, no model or desktop bridge. The Windows installer is not ready.
