# Aeris Bridge — protótipo 0.4.0a3

Fontes: texto manual, Capture e Snippets (módulo ativo e autorização de leitura). Importação explícita, em memória.

| Fluxo | Operações | Saída |
|---|---|---|
| Expand → Text | Expandir abreviações, remover espaços excedentes | Prévia |
| Translate → Email | Guia de 12 frases, modelo formal de atualização | Assunto e mensagem |
| Text → Capture | Remover espaços excedentes | Prévia; criar anotação por confirmação |

Permissões separadas por leitura de cada fonte, execução, gravação no Capture e cópia. Nenhuma transferência externa, voz, envio de e-mails, execução arbitrária ou persistência de fluxos. Não é um editor de workflows genérico. A correção ortográfica/gramatical automática segue pendente no Text. O motor avançado de tradução não é chamado por Bridge.

A validação é preliminar, em Linux, não uma auditoria de segurança. Use dados fictícios.
