# Integrated first-run AI preparation

The next desktop candidate includes an optional setup entry on the installer's final page and an in-app button. Explicit user consent is required before invoking WinGet (Ollama.Ollama, exact official source, default manifest hash validation) or downloading the selected model. Two local choices: Qwen2.5 1.5B (~1 GB text, 3 GiB free model storage) and Qwen2.5-VL 3B (~3.2 GB text/images, 6 GiB free model storage). Extra space for Ollama/runtime is needed; performance depends on hardware. Models are downloaded from Ollama, not redistributed in Aeris. Sources: https://ollama.com/library/qwen2.5:1.5b and https://ollama.com/library/qwen2.5vl:3b; https://docs.ollama.com/faq and https://docs.ollama.com/windows.

Aeris launches its own loopback server on 127.0.0.1:11435 with OLLAMA_NO_CLOUD=1 and an isolated model directory; it does not modify the user's existing Ollama settings or terminate another server. It validates the local model with a fixed synthetic greeting and stores only the approved model name. Subsequent launches restore the service without downloads or automatic chat consent. No mic or screen permission is granted. Cancellation can leave already installed dependencies or partially downloaded model files. WinGet may be absent on Windows Server/older Windows; manual official installation remains a fallback. The native pt-BR speech resources and optional experimental internal meeting audio are not bundled by this change.

Requires Windows client end-to-end install, download, text/vision performance and lifecycle verification plus normal distribution review before publishing a new release. Existing public RC1 remains unchanged.

## Setup UX candidate (separate review branch)
A persistent progress panel shows completed stages and indeterminate activity while WinGet or the model pull runs. It does not invent byte percentages. Assistant operations are temporarily disabled during the serialized worker; the draft remains editable. Cancellation is explicit, may leave dependencies or partial downloads, and does not imply rollback. Restore checks the existing model without claiming a fresh inference test. Source tests do not prove native install or download behavior. No public package is changed.
